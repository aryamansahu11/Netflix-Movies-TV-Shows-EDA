# Netflix Movies and TV Shows - Exploratory Data Analysis

## Project Overview
This project performs Exploratory Data Analysis (EDA) on the Netflix Movies and TV Shows dataset using Python. The goal is to understand content distribution, release trends, country-wise contributions, ratings, and movie durations through data analysis and visualizations.

## Dataset
- Source: [Kaggle - Netflix Movies and TV Shows](https://www.kaggle.com/datasets/shivamb/netflix-shows)
- Rows: 8,807
- Columns: 12

## Tools and Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Project Workflow
1. Data loading and inspection
2. Dataset structure overview
3. Missing value analysis
4. Summary statistics
5. Data visualization
6. Key findings and conclusion

## Visualizations
- Movies vs TV Shows
- Content by Release Year
- Top 10 Countries
- Content Ratings
- Distribution of Movie Durations

## Key Findings
- The dataset contains 6,131 Movies and 2,676 TV Shows.
- Movies make up approximately 69.6% of the dataset.
- The United States is the largest content contributor, followed by India and the United Kingdom.
- Much of the content was released during the 2010s.
- The average movie duration is approximately 99.57 minutes, while the median is 98 minutes.
- Most movies have a duration of approximately 80–120 minutes.

## Conclusion
The analysis provides insights into Netflix's content distribution, release trends, country-wise contributions, ratings, and movie durations. Data cleaning, summary statistics, and visualizations helped identify meaningful patterns in the dataset.
